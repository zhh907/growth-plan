案 1-3:入口、过滤器、括号

CASES 1-3: ENTRY, FILTER, PARENS
1. Zero output + exit 0 = missing if __name__ guard; Python read the file as a dictionary.
2. stop=tool_use but tools=[] — a typo in MY filter. When data (block types) contradicts the assumption (filter), trust the raw dump.
3. resp.content() → 'list' is not callable: parens mean CALL; attributes are taken, not called.
案 4-6:结构三连
④ return None 缩进进了 for 循环 → 永远只跑一轮。缩进 = 归属,和 YAML/compose 同病。
⑤ 结果块类型三连错:tool_call(不存在)→ tool_use(方向反了,上游报中文错误 [1213])→ tool_result(对)。协议方向:assistant 发 tool_use,user 回 tool_result。
⑥ content 塞了裸字典 output,应为块列表 results —— 报错里 messages.2 直接点名第几条消息。
CASES 4-6: THE STRUCTURE TRIPLE
4. return None indented inside the for loop → exactly one round per run. Indentation = membership.
5. Result-block type saga: tool_call (nonexistent) → tool_use (wrong direction, upstream Chinese error [1213]) → tool_result (correct). Direction: assistant sends tool_use; user replies tool_result.
6. content held a bare dict (output) instead of the list (results) — the error named messages.2 exactly.

三、三个新现象

① thinking 块
glm 每轮先吐一个思考块,再吐工具调用。无害:我们把 resp.content 整包存回历史,思考块随行。
代价:thinking 计入输出预算,max_tokens 要按"思考+说话"之和留(最终 16000,实用 7828)。
① THINKING BLOCKS
Each round glm emits a thinking block before the tool call. Harmless: we store resp.content wholesale, thinking rides along.
Cost: thinking counts against max_tokens — budget for think + speak (final cap 16000, actually used 7828).
② 幻觉自纠(errors-as-data 实战)
模型臆断文件 1200 行,拉了越界 chunk,撞上我们的错误字典,下一轮自我纠正 —— 措辞是"according to the user's correction"(工具结果骑在 user 角色上)。
Step A 设计的错误返回,在今天救了 Step B 一命。
② HALLUCINATION, SELF-CORRECTED
The model asserted 1200 lines, requested out-of-range chunks, hit our error dicts, and corrected itself next round — phrasing: "according to the user's correction" (tool results ride the user role).
The error-as-data design from Step A saved Step B's run today.
③ UTF-16LE + 成本警钟
MetaEditor 默认存 UTF-16:.mq4 按 UTF-8 读,每字符夹一个空字节,行数翻倍(2475 vs 1228)。模型自己适应了;工具层该做 BOM 嗅探(排队中)。
一次审计 in=206,020:每轮重发全部历史,输入随轮数平方级膨胀 —— 工具粒度和 prompt caching 因此值钱。
③ UTF-16LE + THE COST BELL
MetaEditor saves UTF-16 by default: reading it as UTF-8 interleaves null bytes and doubles the line count (2475 vs 1228). The model adapted; the tool layer should BOM-sniff (queued).
One audit cost in=206,020: full history re-sent every round → quadratic input growth. This is why tool granularity and prompt caching pay.
