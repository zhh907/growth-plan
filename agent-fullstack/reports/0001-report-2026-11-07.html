二、报错原句精读 Error Messages

每句左右镜像:左侧中文解读,右侧英文原文与要点 · Each block mirrored: CN interpretation left, EN original & takeaway right
① 凭证缺失(实为变量名拼错)
API key 必须放在 Authorization 请求头里(Bearer 方案)。
语法:required in... 被动语态;scheme 此处=方案/机制。
要点:报错说缺 key 而你确实设了 key 时,先怀疑变量名。
① CREDENTIAL MISSING (actually a variable-name typo)
API key is required in Authorization header (Bearer scheme) Grammar: "required in..." passive voice; "scheme" here means mechanism, not plot.
Takeaway: when an error says "missing key" but you set one, suspect the variable name first.
② 模型不可用(分组配置问题)
该分组下没有任何已配置的账号支持 glm-5.3。
语法:configured 过去分词作定语。
要点:模型可用性取决于 key → 分组 → 渠道配置,不是模型本身的属性。
② MODEL UNAVAILABLE (group config issue)
Model "glm-5.3" is not supported by any configured account in this group Grammar: "configured" — past participle used as attribute.
Takeaway: model availability is a property of key → group → channel config, not of the model itself.
③ 拼写错误击穿安全网
名称错误:未定义 'Excepetion'。你是想写 'Exception' 吗?
要点:Did you mean 是 Python 和 Google 共用的标准纠错句式;except 块里有 bug 时安全网失效。
③ TYPO THAT BROKE THE SAFETY NET
NameError: name 'Excepetion' is not defined. Did you mean: 'Exception'? Takeaway: "Did you mean" — the standard correction pattern in Python and Google alike; a bug inside except defeats the safety net.
④⑤ 访问了不存在的属性 ×2
ThinkingBlock / SignatureDelta 对象没有 text 属性。
要点:has no attribute = 访问不存在的属性。响应内容是类型块数组,按类型解析,永远不要按位置猜。
④⑤ NON-EXISTENT ATTRIBUTE ×2
'ThinkingBlock' object has no attribute 'text' 'SignatureDelta' object has no attribute 'text' Takeaway: response content is a TYPED block array — parse by type, never by position.
⑥ 处理异常时又炸出异常
处理上述异常的过程中,又发生了另一个异常。
要点:日志里看到这句,直接检查 except 块本身,九成是它有 bug。
⑥ EXCEPTION INSIDE EXCEPTION HANDLING
During handling of the above exception, another exception occurred Takeaway: see this line → inspect the except block itself. Nine times out of ten it's buggy.

三、词汇表 Vocabulary(19 terms · 4 themes)

主题 1 · 协议与请求
endpoint 端点 — 服务接受请求的 URL 地址
Bearer 持有者 — Authorization: Bearer sk-xxx 认证方案
relay 中转 — 转发 API 请求的代理服务
probe 探测 — 验证是否真能用的小测试请求
deep health check 深度健康检查 — 发真实请求,而非只看状态上报
THEME 1 · PROTOCOL & REQUESTS
endpoint — the URL address where a service accepts requests
Bearer — the auth scheme in "Authorization: Bearer sk-xxx"
relay — a proxy service that forwards API requests to providers
probe — a tiny test request that checks if something actually works
deep health check — verifying by sending a REAL request, not just reading status
主题 2 · 流式
streaming 流式 — 边生成边接收,不是憋完再给
SSE (Server-Sent Events) 服务器推送事件 — 服务端持续推送的 Web 技术
buffer / buffering 缓冲 — 攒一批再转发(打字机效果的杀手)
flush 冲刷 — 强制把缓冲区内容立刻输出
bisection 二分定位 — 每次测试砍掉一半可能性,定位坏的那层
THEME 2 · STREAMING
streaming — receiving output piece by piece as it is generated
SSE (Server-Sent Events) — a web technology for a server to push events continuously
buffer / buffering — holding data in a queue before passing it on (kills the typewriter effect)
flush — force buffered output out immediately
bisection — cutting the problem in half with each test to locate the failing layer
主题 3 · 解析与防御
allowlist / denylist 白名单/黑名单 — 只认想要的 vs 只挡知道的
defensive parsing 防御性解析 — 永远假设输入是坏的
chatter 废话 — 模型在正经答案前加的客套话
markdown fence 代码围栏 — ``` 包裹,会让 json.loads 炸
hallucination 幻觉 — 貌似合理实则错误的输出
THEME 3 · PARSING & DEFENSE
allowlist / denylist — accept known-good (survives new types) vs block known-bad (breaks on new types)
defensive parsing — always assume the input is malformed
chatter — polite filler text the model adds before the real answer
markdown fence — the ``` wrapper that breaks json.loads
hallucination — plausible-looking but wrong output
主题 4 · 安全与业务
compromise 泄露/攻破 — 秘密一旦暴露即视为失守
rotate / rotation 轮换 — 作废旧凭证换新的
signature 签名 — 防篡改的加密证明
mitigation 缓解措施 — 降低风险严重程度的动作
rollback 回滚 — 恢复到上一个可用版本
deploy to production 部署到生产环境 — 周五晚上干这事是经典反面教材
THEME 4 · SECURITY & BUSINESS
compromise — a secret being exposed = treated as broken
rotate / rotation — replacing a leaked secret with a new one
signature — a cryptographic proof that content was not tampered with
mitigation — an action that reduces the severity of a risk
rollback — reverting a deployment to the previous working version
deploy to production — doing this on Friday night is the classic anti-pattern
