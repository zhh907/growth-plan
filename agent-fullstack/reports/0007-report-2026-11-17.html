一、今天的五个概念 Five Ideas, Told with Examples

每个概念配一个你熟悉的例子 · Each idea comes with an example you already know
1 · 路由:先分诊,再派单
前面学的编排者-评审、扇出,分工是焊死的:每篇代码必走同一条流水线。路由是先看病人是谁再决定送哪个科。分诊护士(router)不治病,只填一张单子交标签;各科医生(specialist)拿着自己的提示词接诊。你跑的三个文件,三个走了三个科,一个都没送错。
1 · ROUTING: TRIAGE FIRST, THEN DISPATCH
The orchestrator-critic and fan-out patterns you built earlier divide labor in welded ways: every paper flows the same pipeline. Routing means looking at the patient before choosing the department. The triage nurse (router) never treats — it fills a one-label form; each specialist answers with its own prompt. Your three files went to three departments; not one was misdelivered.
2 · 代码里的路由 = 分类 + 查表
你问"选择发生在哪",答案是:route = call_router(text) 拿到标签,SPECIALISTS[route] 查字典取出提示词——没有 if/else 链。specialist 的全部差异就是配置表里的一行:提示词、预算,生产里再加工具和模型档位。就像你的下单函数:magic number 一换,同一台机器服务另一套 EA。
2 · ROUTING IN CODE: CLASSIFY, THEN LOOK UP
You asked where the choice happens. Answer: route = call_router(text) returns a label; SPECIALISTS[route] pulls the prompt from a dict — no if/else chain. A specialist is just one row in a config table: prompt, budget, and in production also tools and model tier. Like your order function: change the magic number and the same machine serves another EA.
3 · forced tool use:逼模型填表,不许自由发挥
tool_choice={"type":"tool","name":...} 是 API 层的硬开关:这一轮只准调这个工具、只准通过参数槽交卷。0003 的工具是"模型用我们的功能",今天的是"模型填我们的表"——假工具,没有 def,参数 schema 就是答题卡。治的就是 0008 那次自由文本格式漂移。
3 · FORCED TOOL USE: FILL THE FORM, NO FREE PROSE
tool_choice={"type":"tool","name":...} is a hard API switch: this turn must call that tool and only that tool, submitting through its parameter slots. In 0003 tools meant the model uses our functions; today it means the model fills our form — a fake tool with no def, whose schema is the answer sheet. This is the cure for 0008's free-text format drift.
4 · 结构化只给代码要消费的字段
代码只分支一个东西:路由标签。所以只有标签进了 schema;医生的万字长答案塞在一个字符串字段里,给人看,不解析。0009 给 findings 数组建 schema 是因为要逐条数数——需求不同,结构化范围不同。schema 是工具,不是礼服。
4 · SCHEMA ONLY WHAT CODE CONSUMES
The code branches on exactly one thing: the route label. So only the label is schema-enforced; the doctor's thousand-word answer rides in one string field — for humans, never parsed. In 0009 the findings array got a schema because Python counted them line by line. Different needs, different schema scope. A schema is a tool, not formalwear.
5 · 送错科的防线:unsure + out_of_scope
路由的经典事故:病人送错科,错科医生硬着头�皮看——不会说"这不是我的病",只会自信地答错。两道防线:router 拿不准可以交 unsure 走通科;医生的答题卡上有 out_of_scope 布尔位,提示词明写"超出职责必须报告,不许猜"。
5 · MISROUTE DEFENSE: unsure + out_of_scope
The classic routing accident: the wrong-department doctor treats anyway — it will never say "not my disease", only answer wrongly with confidence. Two barriers: the router may submit unsure and land in the generalist's room; the specialist's answer sheet carries an out_of_scope boolean, and its prompt says plainly: report it, never guess.

二、今日一战 Today's Battle: The Explain Doctor Who Lost His Voice

症状 → 根因 → 修复,数字说话 · Symptom → root cause → fix, told with numbers
病状:路由对了,答案却是空的
explain_me.py 路由正确,医生却一言不发。账单露了马脚:out=1024,正好顶到 max_tokens 上限。根因是 remediation 清单里挂了很久的那条:max_tokens 是 thinking 和 text 共享的池子——讲解科医生思考写得长,把交卷额度烧光,answer 字段根本没写出来。
修复两刀:每科独立预算(explain 给 4096);stop_reason == "max_tokens" 时 stderr 报警——截断的答案不可信,宁可叫,不许静默混过去。复跑:out=1246,答案完整,还带出 cache_read=256。
顺带一句:同场的手搓 .env 解析器也被引号坑了(base_url 带着 "https://" 外层的引号,URL 缺协议),换标准 load_dotenv 一行解决。标准库存在的意义,就是别人已经替你踩过这些坑。
SYMPTOM: RIGHT ROUTE, EMPTY ANSWER
explain_me.py routed correctly, then the doctor said nothing. The bill gave it away: out=1024, pinned exactly at the max_tokens ceiling. Root cause was the long-standing item on the remediation list: max_tokens is a pool shared by thinking and text — the explainer thought at length, burned the submission budget, and the answer field never got written.
Two fixes: per-specialist budgets (explain gets 4096), and a stderr alarm when stop_reason == "max_tokens" — a truncated answer cannot be trusted; fail loud, never let it slip through. Re-run: out=1246, full answer, plus cache_read=256.
Same sitting: the hand-rolled .env parser tripped on quotes (base_url kept its quotation marks, so the URL "had no protocol"); the standard load_dotenv replaced ten lines with one. Standard libraries exist precisely because someone already hit these traps for you.

三、Today's English 今天遇到的英语

只收今天真实碰到的 · Drawn only from today's real encounters — click the right column to listen
① triage — 分诊
router 提示词第一行 like a triage nurse。/triːˈɑːʒ/,法语来的医疗词:急诊室里决定谁先看病的动作。文件安全圈也用它:triage the bugs = 给 bug 按轻重排队。这节课的名字就住在这行提示词里。
① TRIAGE
Line one of the router prompt: like a triage nurse. /triːˈɑːʒ/, a medical word from French: the act of deciding who gets seen first in an ER. Security teams use it too: triage the bugs — rank bugs by severity. The whole lesson is named inside this one line.
② forced tool use — 强制工具调用
你问"这种方式专业名词是什么",答案。forced = 被迫的。Anthropic 官方文档的栏目名就叫 Forcing tool use。兄弟词:forced marriage(被迫的婚姻)——同样是"没有选择权"。OpenAI 那边对应 tool_choice: required。
② FORCED TOOL USE
Your own question: "what is the professional term for this?" Forced = no choice in the matter. Anthropic's docs section is literally titled Forcing tool use. Sibling word: forced marriage — same lack of choice. OpenAI's counterpart is tool_choice: required.
③ say so — 照实这么说
bug_hunt 提示词 say so honestly。这里 so 是代词,替代前面整个句子(文件是干净的)——"是干净的,就照实说它是干净的"。同类:I told you so(我早说过吧)。两个词顶一整句,英语的省略艺术。
③ SAY SO
From the bug_hunt prompt: say so honestly. Here so is a pro-form standing for the whole preceding clause ("the file is clean") — if it is clean, say THAT, and say it honestly. Same family: I told you so. Two words carrying a full sentence — English compression at work.
④ what it needs is... — 强调句型
explain 科的路由定义:what it needs is an explanation of how it works。这叫假拟分裂句(pseudo-cleft):what 从句当主语,专门用来点名后面的东西——"它需要的,是讲解"。比平铺的 it needs an explanation 重一档。写提示词定义类别时很好用。
④ WHAT IT NEEDS IS...
The explain route's definition: what it needs is an explanation of how it works. This is a pseudo-cleft: the what-clause serves as subject, built to spotlight the noun after is — "what it NEEDS is an explanation". One notch heavier than plain "it needs an explanation". Handy when defining categories in prompts.
⑤ none of the above fits — 上述皆非
unsure 的定义句。注意 fits 是单数:none of + 名词在美式英语里惯用单数动词。the above = 上述内容(选择题的 E 选项)。后面还挂了个 confidently——不是"都不匹配",是"没把握的匹配不算",给 router 留了承认不确定的台阶。
⑤ NONE OF THE ABOVE FITS
The unsure route's definition. Note fits is singular: "none of + noun" customarily takes a singular verb in American English. "The above" = the items listed above (choice E on a multiple-choice question). And it ends with "confidently" — not "nothing matches" but "no match I'd bet on", leaving the router a dignified way to admit doubt.
