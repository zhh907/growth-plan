## Conventions(每个轨道统一)

- `agent.md` — AI 助教说明书:打开文件夹先读它,知道该怎么带这条轨道
- `00-roadmap.md` — 总路线图,阶段完成后打勾
- `01-learning-log.md` — 学习日志,新条目放最上面
- `02-current-task.md` — 当前任务 checklist,接续学习第二个读这个

## Rules

- 所有日志、commit message、代码注释一律英文(英语浸润)
- 讲解用中文,材料用英文
- 语言学习中的英语轨道与两条技术轨道绑定(文档/报错/术语全英文),不单独排期
- 每次学习结束更新对应轨道的 current-task 与 learning-log
